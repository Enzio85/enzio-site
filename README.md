# Enziocards Pikaiou

Boutique en ligne de cartes illustrées.

## Nom de domaine

Le domaine visé est `enziocardspikaiou.com`. Il faut l’acheter auprès d’un bureau d’enregistrement, puis renseigner ce domaine dans les paramètres GitHub Pages du dépôt.

## Aperçu local

Ouvrez `index.html` dans un navigateur.

## Activer les paiements Stripe

1. Créez un compte Stripe et complétez la vérification.
2. Dans Stripe, créez un lien de paiement pour vos cartes.
3. Dans `script.js`, remplacez `const STRIPE_PAYMENT_LINK = "";` par votre lien Stripe.
4. Publiez le changement sur GitHub Pages.
